## 🛠️ Tech Stack & Architecture

- **Markup & Styling:** Semantic HTML5, Tailwind CSS (CDN / Just-In-Time)
- **Interactivity:** Vanilla JavaScript (ES6+), Interactive Console Logic, Dynamic Modal Management
- **Typography:** Inter & JetBrains Mono (Google Fonts)
- **Icons:** Font Awesome 6.5.1

## 🌟 Key Features

- **Interactive Developer Console:** Switch between mock code files (`profile.py`, `schema.sql`, `stack.json`) directly in the hero section.
- **ATS-Optimized Resume Summary Modal:** Clean, structured modal with a dedicated print/PDF export stylesheet.
- **Privacy-First Communication:** Phone-number-free contact section prioritizing direct professional email and verified profile links.
- **Verified Credentials:** Showcases 5 verified HackerRank certifications (Problem Solving, Python, Java, SQL, JavaScript).
